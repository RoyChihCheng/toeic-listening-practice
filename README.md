# TOEIC Listening Practice (新制多益聽力線上練習平台)

專為多益聽力練習與家教學生打造的免安裝、即開即練線上模考系統。

## 平台特色
- **10 回完整聽力模擬測驗**：每回包含 Part 1（照片描述）、Part 2（應答問題）、Part 3（簡短對話）、Part 4（簡短獨白）共 100 題。
- **雲端音檔串流**：所有音訊檔及題目圖片均託管於 Cloudflare R2，網頁載入迅速，節省頻寬與儲存空間。
- **即時自動評分**：提交後立即顯示各 Part 正確率、答對題數與百分比。
- **錯題快速檢視**：自動標記錯題，並可一鍵跳轉回原題查看題目、音訊與正確解答。
- **進度自動儲存**：作答狀態即時保存於瀏覽器 LocalStorage，避免誤觸重整造成進度遺失。
